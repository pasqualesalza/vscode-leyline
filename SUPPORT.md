# Support

## Getting help

- **Bug reports and feature requests**: open an issue on the
  [GitHub Issues](https://github.com/pasqualesalza/vscode-leyline/issues/new/choose) page.
- **Questions and discussions**: use
  [GitHub Discussions](https://github.com/pasqualesalza/vscode-leyline/discussions).

## Before opening an issue

1. Check the [Troubleshooting](README.md#troubleshooting) section in the README.
2. Open **Output → Leyline** in VS Code for error details.
3. Search [existing issues](https://github.com/pasqualesalza/vscode-leyline/issues)
   to see if it has already been reported.

## Security vulnerabilities

Please do **not** report security vulnerabilities via public GitHub issues.
Email [pasquale@kaiko.ai](mailto:pasquale@kaiko.ai) instead.
