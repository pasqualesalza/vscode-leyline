## Choose a provider

Leyline works with two types of AI backends:

- **Codestral** — Mistral's cloud FIM model. Fast and accurate, requires an API key from [console.mistral.ai](https://console.mistral.ai/).
- **Ollama** — any FIM-capable model running locally on your machine. No API key, no cloud calls.

[Select Provider](command:leyline.selectProvider)
